# Discord Tickets

Утилита discord-tickets в экосистеме Digital Drugs Tech.

## Контекст в экосистеме
- Зависит от: Node.js, npm
- Интегрируется с: экосистемой Digital Drugs Tech
- Деплоится: Standalone приложение

## Быстрый старт для разработчика
```bash
# Клонирование и установка зависимостей
git clone <repo>
cd discord-tickets
npm install

# Настройка конфигурации
cp .env.example .env
# Заполнить необходимые параметры

# Запуск разработки
npm run dev
```
